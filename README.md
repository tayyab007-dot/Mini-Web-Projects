# 🚀 Mini Web Projects Hub

Welcome to my central hub for small, interactive web projects! This repository serves as a megastore for my front-end and JavaScript experiments. Instead of creating separate repositories for every single minor project, I’ve organized them all right here into dedicated folders.

Explore the folders above to see the source code, or check out the project directory below to learn what each one does.

## 📂 Project Directory

Below is a breakdown of the 7-8 small projects housed in this repository:

| Project Name | Tech Stack | Description |

| **🎵 DSA Music Player** | HTML, CSS, JavaScript | A functional music player built while learning and implementing Data Structures and Algorithms logic. |

## 🛠️ Core Technologies Used

* **HTML5:** Semantic structuring and clean document layout.
* **CSS3:** Custom styling, layouts (Flexbox/Grid), and responsive design.
* **JavaScript (ES6+):** Asynchronous API fetching, event handling, and DOM manipulation.
